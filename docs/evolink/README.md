# EvoLink Luna live demo

[Watch the English video](shanghai-lax.mp4) · [Final frame](shanghai-lax.png) · [Machine-readable run summary](run-summary.json)

The recording shows a one-way Shanghai → Los Angeles (LAX) flight search for October 29, 2026, one adult, economy. It was captured on October 22, 2026. No flight was selected or booked.

The operation/target model was `gpt-6-luna-decisions` on EvoLink Decisions, and field text was generated by `gpt-6-luna` on EvoLink Chat Completions. The final attempt used an independent completion callback, with no operator supplying browser actions.

## Measurement boundary

- Agent time: **24,868 ms**, from first prediction through the successful page observation. Browser setup and initial navigation are excluded.
- Successful-attempt requests: **26 Decisions + 4 text**, all HTTP 200.
- Video: **25.6 seconds**, 1536 × 1000, 30 fps, H.264, original speed, silent and English.
- All **25,074 ms** of capture are retained, followed by a 500 ms final hold. The agent counter freezes at its logged end during the 206 ms recorder tail and final hold.
- Median logged decision latency: **536.5 ms**; the panel uses the upstream integer rounding.
- Only the top 64-pixel navigation/account strip is cropped. The original browser task area is pasted at native resolution. No webpage task content was redrawn, and no intermediate errors or loading waits were removed.

The surrounding layout follows the upstream renderer: browser at left, timer/progress/status/latency at right. The model attribution was changed to the models actually used. The earlier simple recording and upstream original assets remain separate from this rerender.

## Verification and failures

The final observation passed 12 checks: Google Flights results route, one-way setting, one passenger, economy, Shanghai origin, Los Angeles destination, October 29 departure, 2026 year, visible flight options, English content, one-adult wording and matching itinerary departure dates. The temporary test browser and relay exited and their private profile was removed. No screencast errors were recorded.

This was **one verified attempt after fixes**, not first-attempt success. Four earlier live attempts stopped on a singleton-choice HTTP 400, premature completion during loading, an unsuitable autocomplete query, and premature completion before Search. Singleton handling and the optional completion guard were added during that work. An unsuitable date-field text value and other imperfect intermediate steps remain visible in the successful run.

A later November/December fare-calendar task **did not complete automatically**: the agent repeated opening/closing the date picker and hit its 60-action budget after 118 decisions and 5 text calls. Browser research completed afterward by an operator is not included as an agent success.

This evidence does not establish general reliability, probability calibration, fare availability, or total dollar cost. The run summary publishes task measurements and source hashes. Private environment files, raw browser sessions, local paths and unrelated research records are not published.
